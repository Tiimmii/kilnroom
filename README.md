# Kilnroom

A ceramics studio site (classes and a monthly shelf), built as a Next.js app from the callmelord animation code and the Hallmark "Kiln" theme.

```bash
npm install
npm run dev
```

| Where | What |
| --- | --- |
| `data/site.js` | All copy, the firing table, shelf, classes, questions and photo credits. |
| `components/` | `Nav`, `Hero`, `Statement`, `Shutter`, `Firing`, `Shelf`, `Classes`, `Questions`, `Footer`, `PostFooter`. |
| `lib/gsap.js` | GSAP, ScrollTrigger and SplitText registration. |
| `app/globals.css` | Page styles. Tokens and base rules are in `app/tokens.css` and `app/base.css`. |
| `public/images/` | Stand-in photographs from Wikimedia Commons, credited in the footer. Replace them with your own. |

The studio, its classes and the email address are placeholders. Replace the photos and copy before publishing.
